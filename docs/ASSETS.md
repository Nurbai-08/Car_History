# Демонстрационные фотографии

Фотографии предназначены только для оформления вымышленных seed-карточек; не подтверждают модель, комплектацию или состояние автомобиля. На карточках есть отметка «Демонстрация».

- BMW: https://images.unsplash.com/photo-1555215695-3004980ad54e
- Toyota: https://images.unsplash.com/photo-1621007947382-bb3c3994e3fb

Оригиналы получены с Unsplash. Локальные копии — `apps/api/demo-assets/`. Seed помещает их в закрытое S3-хранилище. Пользовательские автомобили получают нейтральный placeholder, пока владелец не загрузит фото.
